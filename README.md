# تطبيق تحديد قطع غيار السيارات

## 📋 الوصف
تطبيق متقدم للتعرف على قطع غيار السيارات من خلال الأرقام التسلسلية (VIN) حسب نوع السيارة والمحرك (سكنار 1.0)

## ✨ المميزات
- البحث عن قطع الغيار باستخدام الرقم التسلسلي (VIN)
- تحديد نوع السيارة والمحرك تلقائياً
- قاعدة بيانات شاملة لقطع الغيار
- واجهة سهلة الاستخدام
- تصفية وتصنيف القطع حسب الفئة

## 🛠️ التكنولوجيا المستخدمة
- Python 3.x
- Flask (للواجهة الويب)
- SQLite (قاعدة البيانات)
- API للبحث والاستعلام

1. استنساخ المستودع
2. تثبيت المتطلبات: `pip install -r requirements.txt`
3. تشغيل التطبيق: `python main.py`
